### How I build these

**The guards are the work.** A comment-to-DM flow is twenty minutes. Making one
that does not reply to its own replies forever, does not get the account
restricted for messaging the same person repeatedly, and does not send
duplicates when Meta retries a webhook, that is the part worth paying for.
Every README here leads on the failure modes rather than the happy path.

**Nothing here touches real client data.** Sample payloads are invented, and
they use the reserved `.test` domain so nothing can accidentally resolve or
receive mail. No credentials, no keys, no exports.

**No scraping behind logins.** Instagram and Faire both prohibit it, whatever a
tutorial told you. The tools here use documented APIs and public sources.
